\# Lab 01 – Static Website Hosting using AWS S3



\## Aim

To deploy and host a static website using Amazon S3.



\## AWS Service Used

Amazon Simple Storage Service (S3).



\## Procedure

1\. Create an S3 bucket.

2\. Upload the Frozen Yogurt Shop website files.

3\. Configure public read permissions.

4\. Enable static website hosting.

5\. Configure index.html as the index document.

6\. Access the website using the S3 website endpoint.



\## Result

Successfully deployed and hosted the Frozen Yogurt Shop static website using AWS S3.
